# Bicolandia

Bicolandia is a native Android tourism guide for the Bicol region of the Philippines, built with Kotlin and Jetpack Compose.

> Built with AI coding tools. I defined the features, directed the AI, tested the app, and fixed errors.

## Features

- Provinces and places in the Bicol region
- Stays and a travel guide
- Itinerary planner
- Map screen
- Favorites
- Sign-up and login

## Tech stack

- Kotlin
- Jetpack Compose
- Android Studio
- Data stored on the device (no backend server)

## How to run

1. Install [Android Studio](https://developer.android.com/studio).
2. Open this folder as a project and let Gradle sync.
3. Run the app on an emulator or an Android device.

## Known limitations

- All data is stored on the device only; there is no online account or server.
- Passwords are saved as unsalted SHA-256 hashes. This is acceptable for a local demo but should be improved before real use.
